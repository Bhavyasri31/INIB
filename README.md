# Weather Application

A real-time weather application built using HTML, CSS, JavaScript, Node.js, Express.js, and OpenWeatherMap API.

## Features

- Search weather by city
- Temperature in Celsius
- Weather condition
- Humidity
- Wind speed
- Responsive user interface

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- OpenWeatherMap API
